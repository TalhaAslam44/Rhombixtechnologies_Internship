# Rhombix Technologies Internship – Data Science & Machine Learning

This repository contains the tasks I completed during my internship at **Rhombix Technologies**, covering three domains: **Data Science**, **Machine Learning**, and **Data Analysis**. Each task is organized in its own folder with the relevant code, datasets (or links to them), and a brief explanation of the approach used.

## 📌 About the Internship

During this internship, I worked on real-world problems spanning classification, prediction, recommendation systems, computer vision, and exploratory data analysis — applying core data science and machine learning concepts using Python and its data/ML ecosystem.

## 🚀 Tasks Overview

### 🔹 Data Science

**1. Titanic Classification**
Built a classification model to predict passenger survival on the Titanic based on features such as age, gender, passenger class, and fare. Involved data preprocessing, feature engineering, and model evaluation.
- **Tech used:** Python, Pandas, NumPy, Scikit-learn, Matplotlib/Seaborn

**2. Stock Prediction**
Developed a model to predict stock price trends using historical stock data, applying time-series analysis and regression/ML techniques.
- **Tech used:** Python, Pandas, NumPy, Scikit-learn, Matplotlib, (optionally LSTM/TensorFlow)

### 🔹 Machine Learning

**3. Music Recommendation System**
Built a recommendation engine to suggest songs to users based on listening history/preferences, using collaborative filtering or content-based filtering techniques.
- **Tech used:** Python, Pandas, Scikit-learn, Cosine Similarity / Matrix Factorization

**4. Image Recognition**
Implemented an image classification model to recognize and categorize images using deep learning/CNN-based approaches.
- **Tech used:** Python, TensorFlow/Keras or PyTorch, OpenCV

### 🔹 Data Analysis

**5. Data Collection & Cleaning**
Collected raw data from various sources and performed data cleaning — handling missing values, duplicates, and inconsistent formatting to prepare it for analysis.
- **Tech used:** Python, Pandas, NumPy

**6. Exploratory Data Analysis (EDA)**
Performed in-depth exploratory analysis to uncover patterns, trends, and relationships within the dataset using statistical summaries and visualizations.
- **Tech used:** Python, Pandas, Matplotlib, Seaborn
